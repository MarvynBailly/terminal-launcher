Terminal Launcher

One terminal is both the lock screen and the home screen. Log in, then run the phone by typing.

Log in

  • The demo password. Click to type it.

Then try

  • List apps. Tap a name to open it.
  • Launch an app, or just type its name.
  • Read notifications.
  • Toggle the flashlight.
  • Dim the screen.
  • Switch the color theme.
  • Every command.
  • Back to the lock screen.

Keys

  • TabComplete a command or app name.
  • ↑ ↓Command history.
  • EscLeave an app, back to the terminal.
  • Side buttonScreen off. Wakes to the lock screen.
